# 🚀 YouTube Bulk & Shorts Downloader

Ek simple, tez aur powerful tool jo YouTube Channels, Playlists, ya Single Videos/Shorts ko bulk mein download karne ke liye banaya gaya hai.

---

## ✨ Features

1. **Direct Video & Shorts Support:**
   - Kisi bhi single YouTube video ya Shorts link (`https://youtu.be/...` ya `https://youtube.com/shorts/...`) ko direct download karein.
2. **Channel Bulk Inspector:**
   - Kisi bhi channel ka link ya handle daalein (maslan: `https://www.youtube.com/@MrBeast`).
   - Filter options:
     - ⚡ **Shorts Only:** Channel ki tamam shorts alag se filter ho kar aati hain.
     - 🎬 **Videos Only:** Lambi videos alag se aati hain.
     - ✨ **All Items:** Channel ka tamam content ek sath show hota hai.
3. **Selection Controls:**
   - Checkboxes ke zariye chunain ke kaun si video download karni hai.
   - **"Select All" / "Deselect All"** ka one-click button.
   - Search box se kisi bhi title ko instant filter karein.
4. **Resolution Selection:**
   - **1080p (Full HD MP4)**
   - **720p (HD MP4)**
   - **480p / 360p (Lightweight MP4)**
   - **Audio Only (MP3)**
5. **Live Download Queue & Progress:**
   - Real-time download percentage, speed (MB/s), aur ETA dekh sakte hain.
   - Downloads complete hone par direct "Open Folder" button se folder open kar sakte hain.

---

## 🏃‍♂️ Chalane ka Tareeqa (How to Run)

### Tareeqa 1: One-Click (Windows)
Sirf **`start.bat`** file par double-click karein. Yeh server start karke aapke browser mein **`http://localhost:5000`** auto-open kar dega.

### Tareeqa 2: Terminal se
```powershell
cd Youtube-Bulk-video-downloder
..\.venv\Scripts\python app.py
```

Phir apne browser mein kholein:
👉 **http://localhost:5000**
