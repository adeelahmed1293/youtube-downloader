# 🚀 YouTube Bulk & Shorts Downloader - Chrome Extension

Ek powerful aur zero-error Chrome Extension jo YouTube Channels, Playlists aur Shorts ko directly aapke browser ke andar se bulk mein download karti hai.

---

## ✨ Khas Fawaid (Why This Extension?)

1. **🛡️ Zero Bot Check / Zero Cloud IP Blocks:**
   Yeh extension aapke apne live browser session par chalti hai. YouTube isay kabhi bhi bot block nahi karta!
2. **⚡ Native Chrome Downloads:**
   Direct aapke computer ke `Downloads/YouTube_Shorts/` folder mein high-speed downloads save hotay hain.
3. **🎬 Direct In-Page Interface:**
   YouTube par channel ya shorts browse karte waqt screen par **"⚡ Bulk Downloader"** ka floating button aata hai.
4. **📦 One-Click Multi-Select:**
   Select All, Deselect All, Search Filter aur Quality Options (1080p, 720p, 480p, Audio MP3).

---

## 🏃‍♂️ Chrome Mein Install Karne Ka Tareeqa (30 Seconds)

1. Apne browser mein yeh link open karein:
   👉 **`chrome://extensions`** (Edge mein `edge://extensions`)
2. Top-right corner mein **"Developer mode"** ka switch **ON** karein.
3. Top-left par **"Load unpacked"** button par click karein.
4. Is folder ko select karein:
   📁 `c:\Users\adeel\Desktop\openshorts\Youtube-Bulk-video-downloder\chrome-extension`
5. 🎉 **Done!** Extension aapke browser mein install ho chuki hai!

---

## 💡 Kaise Istemal Karein?

1. YouTube par kisi bhi channel ya shorts page par jayein (maslan: `https://www.youtube.com/@MrBeast/shorts`).
2. Screen ke bottom-right mein **"⚡ Bulk Downloader"** button nazar aayega.
3. Us par click karein, apni pasandeeda videos chunein, aur **"Download Selected"** par click karein!
